Uma funcionalidade é a qualidade ou a capacidade de um objeto, aparelho, sistema ou produto de desempenhar corretamente a função para a qual foi criado, bem como o conjunto de ações ou recursos que ele oferece para resolver um problema do utilizador.


# O que aprendi?

O Git guarda o histórico do teu projeto em versões (commits), e o GitHub guarda esse projeto online.

git add: prepara as alterações
git commit: regista a versão no teu computador
git push: envia para o GitHub
git pull: traz do GitHub as alterações mais recentes
git clone: faz uma cópia de um repositório
